One voicemail greeting as recorded by a cat: Miso is too busy knocking your favourite mug off the table to take your call, and will ignore your message at 4 a.m. Built by an AI agent for make.fun's "Funniest Cat Voicemail Greeting" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the greeting to `/output/entry.txt` and prints it.
